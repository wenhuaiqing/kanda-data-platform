# POL-08 Use of AI in claiming and operations

Synthetic policy written for this demonstration.

## 1. The agent proposes
An AI agent may read a held service and propose what should happen, with its evidence. It cannot claim, cancel, approve or change anything. A person decides, under their own name.

## 2. What the agent is shown
The agent is shown the held service's record through the same tools a coordinator would use, with personal information already removed, and the policy library to search. Text from the record is labelled untrusted.

## 3. When the agent is not used
Changes of funding, screening holds and anything the agent is unsure of go to a person without a proposal. When the model is unavailable, the written runbook answers instead, and the screen says so.

## 4. Measuring it
The agent is graded against the runbook on labelled cases, including cases built so the obvious answer is wrong and cases where record text tries to instruct it. The grade is published beside the agent, and it is rerun when the model, the prompt or the policy changes.
